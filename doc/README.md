## 如何学习

助手负责设计、实现和验证；用户按照每课给出的顺序翻代码、发送请求、观察数据库并提问。用户已有 SQL 和 Go 基础，Gin/Gorm 仍需结合实际业务解释，Redis、RabbitMQ 和 Worker 从基础讲起。

每课先解释业务请求怎样流转，并在每一步附文件链接和准确行号。随后按从零构建的顺序讲结构体、字段和关系、数据库操作、Service、Handler、Router，明确函数调用与返回。引入新概念先给独立最小例子，每个新增函数前有中文作用注释。

每次默认实现一条业务链；用户明确要求更多时按当次要求执行。助手测试通过与用户理解验收分开记录。练习从预测结果、找到一处代码、修改一个字段开始。

代码位置同时提供可点击的相对文件链接和行号，必要时提供路径:行号供 Ctrl+P 定位。不要只让用户看 diff，也不要只罗列抽象架构名词。
